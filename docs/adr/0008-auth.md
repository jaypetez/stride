# 0008. Authentication for Stride Groups

- Status: Proposed (confirmed by spike CLOUD-003)
- Date: 2026-11-01

## Context
Cloudflare has no built-in auth (ADR 0005). We want:
- open source with no per-user vendor fees
- Sign in with Google on Android through Credential Manager (legacy Google
  Sign-In is deprecated)
- a later path to passkeys and email OTP
- auth that is testable offline in Miniflare

## Decision
Use **Better Auth** running inside the Worker with the D1 adapter:
- **Sign-in flow:** Android gets a Google ID token from Credential Manager.
  The Worker verifies it against Google's JWKS and issues a Better Auth
  session.
- **Tokens:** sessions are opaque bearer tokens. Android stores them in
  DataStore + Tink.
- **Sign out:** revokes the session server-side.

Spike **CLOUD-003** must confirm that Better Auth runs on Workers + D1 with
the current runtime. If it doesn't, the fallback is a minimal in-house
implementation: verify the Google ID token with `jose` and store sessions in
D1. That fallback makes this ADR "Superseded".

## Consequences
- Needs Google OAuth client IDs for Android (SHA-256 of the signing cert) and
  for web. These are human-only setup steps.
- The web account-deletion page reuses the same sign-in.
- Passkeys and email OTP are parked follow-ups.
